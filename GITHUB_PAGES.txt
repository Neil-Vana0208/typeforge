TYPEFORGE — GITHUB PAGES QUICK DEPLOY
=====================================

1. Create/sign in to a GitHub account.
2. Create a new repository, for example: typeforge.
3. Upload ALL files/folders inside this Typeforge folder.
   index.html must be at the repository root.
4. GitHub repository -> Settings -> Pages.
5. Under Build and deployment, choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
6. Save and wait for GitHub Pages to publish.
7. Open the generated https://...github.io/typeforge/ address.

If the repository is named typeforge, the URL normally follows the pattern:
https://YOUR-GITHUB-USERNAME.github.io/typeforge/

Do not put the Supabase service-role key in the repository.
