TYPEFORGE RPG COMBAT - UPDATED BUILD

Changes in this build:
- Armored enemies take 2 correct attacks instead of having a shield/timing mechanic.
- Every 5th wave becomes a boss encounter.
- Normal enemy spawning stops when a boss encounter is triggered.
- Existing normal enemies are cleared before the boss appears, so the boss fights alone.
- Bosses have 3 phases / 3 HP. Each successful word advances the boss phase.
- After the boss is defeated, normal spawning resumes on the next wave.
- Training Mode remains separate and unchanged.
- RPG Combat remains always accessible.

Open index.html in a browser to play.
